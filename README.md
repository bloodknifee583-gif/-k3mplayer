# K3M Player

A clean Android local music player built from scratch.

## Features
- Scans music stored on the device (with permission)
- Search by track title or artist
- Play, pause, previous and next
- Dark interface with lime accents

## Build
Run `gradle assembleDebug` with JDK 17 and Android SDK 35, or use the GitHub Actions workflow. The APK is published as the `K3M-Player-debug` workflow artifact.
